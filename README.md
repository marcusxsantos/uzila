# Uzila Connect

Crie um site institucional completo, moderno, responsivo e altamente persuasivo para a empresa Uzila, utilizando o logotipo fornecido como base da identidade visual.

Identidade da marca

A Uzila é uma plataforma de inteligência artificial para atendimento e relacionamento via WhatsApp. Sua missão é transformar conversas em relacionamentos duradouros, ajudando empresas a organizar atendimentos, acompanhar clientes e aumentar conversões.

A personalidade da marca deve ser:

Humana
Inteligente
Acolhedora
Moderna
Confiável
Próxima

A tecnologia deve parecer acessível e amigável, nunca fria.
